# 第1章: 基本的な書き方

Markdownを使って書籍コンテンツを作成する方法を解説します。

## 見出しの使い方

見出しは `#` の数でレベルを指定します。

### 見出しレベル3

見出しは最大3段階まで対応しています。目次の深さは `settings.yaml` の `toc_depth` で調整できます。

## テキストの書き方

通常のテキストはそのまま記述します。**太字**は `**テキスト**`、*斜体*は `*テキスト*` で表現します。

段落は空行で区切ります。字下げは自動で適用されます。

## 箇条書きリスト

- リスト項目1
- リスト項目2
  - ネストしたリスト
  - もう一つのネスト
- リスト項目3

## 番号付きリスト

1. 手順1：プロジェクトフォルダを作成する
2. 手順2：Markdownファイルを配置する
3. 手順3：settings.yamlを編集する
4. 手順4：「生成する」ボタンをクリックする

## 引用

> 引用文はこのように記述します。長い引用文の場合も、自動的にインデントされてスタイルが適用されます。
>
> 複数段落の引用も可能です。

## コードブロック

インラインコードは `このように` バッククォートで囲みます。

コードブロックの例：

```python
def hello():
    print("Hello, World!")
    return True

result = hello()
```

```yaml
# settings.yaml の例
title: 私の本
author: 著者名
language: ja-JP
```
